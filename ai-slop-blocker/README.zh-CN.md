# AI Slop Blocker

[English](README.md) | [简体中文](README.zh-CN.md)

这是一个使用 Sider Code 制作的个人实验，用于给 X 和 Reddit 信息流中的低质量帖子打分，并将它们折叠。它是 [Ecom-Agent-Tools](https://github.com/Ecom-Agent-Tools/Ecom-Agent-Tools) 项目的一部分。

目标是减少花在空泛营销、诱导互动、重复模板和低信息量帖子上的注意力。AI 辅助写作也可以有价值，人写的内容也可能是垃圾。分数越高，代表命中的风险信号越多，**不代表经过统计校准的 AI 写作概率**。

## 使用 Sider Code 重新制作

1. 在 Sider 浏览器扩展中打开 [Sider Code](https://sider.ai/agents/code)。
2. 将检测规则手册上传到自己的 Wisebase。提示词使用的路径是 `AISlop/ai-slop-x-detection-rules.md`；请将它替换为你的实际文档位置，或将文档保存到这个位置。
3. 打开 X 或 Reddit，选择 Code，提供原始 prompt，要求它先读取 Wisebase 文档，再生成脚本。
4. 如果需要更细的要求，可以使用重新生成 prompt。补充你自己的折叠策略，并要求 Code 检查当前页面结构。
5. 检查生成的脚本，通过 Code 保存并启用，然后分别在两个平台检查评分、折叠、Reveal（展开）以及新加载帖子的处理效果。

也可以把保存的 `.user.js` 文件交给 Code，作为继续调整的起点。它是浏览器用户脚本，不是独立的扩展安装包。本次文档更新没有在浏览器中独立验证它与当前网站的兼容性。

## 保存的脚本实际行为

- 使用 JavaScript 规则在本地给提取到的帖子文字打分，并显示附带原因的小评分卡。在 X 上，找到头像元素时会将评分卡放在头像下方；在 Reddit 上则放在身份信息行或帖子容器中。
- 折叠帖子并提供 Reveal 按钮，通过 `localStorage` 记住已展开帖子的 ID。
- 监听页面变化，处理新加载的帖子。
- 不包含外部 AI 调用或上传帖子内容的请求。这里描述的是该脚本的评分逻辑，不代表 Sider 扩展整体的数据处理方式。

**这是一个实验版本，与提示词中的要求存在以下差异：**

- 两个平台实际生效的折叠条件都是 `result.score > 21`。
- `calibrationRate` 在 X 上为 `0.24`，在 Reddit 上为 `0.14`，但按比例折叠没有启用：`recalibrate()` 传入的是 `calibratedFold: false`，计算出的 `foldCount` 没有决定是否折叠。只修改这两个比例，不能改变折叠边界。
- 第一手经历、技术来源等证据会出现在减分信号明细中，但这部分减分总额没有从最终分数中扣除。部分评分规则会另外检查事实支撑。
- 脚本会读取敏感度和动作设置，但固定折叠条件绕过了配置中的 `fold` 阈值；`mark` 也不能可靠地表示“只标记、绝不折叠”。
- 脚本会给促销话术打分，没有实现对平台广告的统一豁免。

## 为自己的信息流选择边界

在作者的人工实验中，X 样本里评分最高的约 10%、Reddit 样本里评分最高的约 6%，已经有比较明显的 slop 特征。随后作者选择了更宽的边界，分别参考前 15% 和前 9%。这些是个人观察与偏好，不是平台整体的内容比例，也不是经过验证的准确率。**保存的脚本没有实现这两个百分比边界。**

如果想复现校准过程，可以分别给自己两个平台信息流中的数百条帖子打分，从高分往下人工阅读，尤其留意候选分界线附近的帖子，再选择自己能接受的分数线，检查实际折叠效果。样本中的百分位不保证后续信息流也会折叠相同比例，遇到同分帖子或信息流变化时尤其如此。

把得到的分平台策略交给 Code，并确认它真正参与了折叠逻辑。如果希望广告保持可见，需要单独提出要求并验证。现有规则主要是面向英文的启发式规则，其他语言及纯图片、视频帖子需要另外评估。
